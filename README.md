## 🧪 Запуск автоматических тестов проекта

В проект включен набор smoke-тестов, написанный с использованием встроенного тест-раннера Node.js (не требует установки тяжелых внешних пакетов):

```bash
# Запуск через npm
npm test

# Или напрямую через Node.js
node --test tests/smoke.test.js
```

Тесты проверяют:
1. Наличие и целостность ключевых файлов (`index.html`, `styles.css`, `app.js`).
2. Корректность мета-тегов и заголовка страницы.
3. Валидность всех прямых контактных ссылок (Telegram, Почта, GitHub).
4. Наличие обязательных секций навигации и всех вкладок артефактов.
5. 100% паритет ключей словарей локализации (RU и EN).
6. Наличие стилей печати для PDF-экспорта.

## 💻 Как открыть локально

### Вариант 1: Просто в браузере
Дважды кликните по файлу `index.html` или перетащите его в окно браузера (Chrome, Edge, Firefox, Safari).

### Вариант 2: Локальный веб-сервер
Если у вас установлен Python или Node.js:

```bash
# Через Python
python -m http.server 8000

# Или через npx serve
npx serve .
```
Откройте в браузере: `http://localhost:8000`.
